Поиск и оценка стоимости через Avito. Бэкенд — python-парсер, запускается через
**forkd**: `dispatch_to_connector` target `"forkd"`, kind `"forkd.run"`, payload
`{ "skill_path": "avito-price/scripts/avito_query.py", "interpreter": "python3",
"args": [...], "timeout_secs": 60 }`. Скрипт печатает ОДИН JSON-объект в stdout —
он приходит в поле `stdout` результата forkd; распарси его и работай с ним.

## Шаг 1. Город (только при первом использовании)

Перед первым поиском вызови с `"args": ["get-city"]`. Если `status` = `need_city` —
**спроси у пользователя**: «В каком городе искать объявления?». Получив ответ, сразу
делай поиск с `--city "<город>"` — город сохранится и больше спрашиваться не будет.
Если вернулось `need_slug` — определи латинский slug сам (часть адреса
`avito.ru/<slug>`: `moskva`, `sankt-peterburg`, `rostov-na-donu`) и вызови
`["set-city","--name","<город>","--slug","<slug>"]`.

## Шаг 2. Сборка запроса

Преврати просьбу в один компактный текст для `--query`:
- Расшифруй сленг: «двухсотый крузак» → `Land Cruiser 200`, «бэха» → `BMW`,
  «айфон 15 про» → `iPhone 15 Pro`.
- Все названные параметры вшивай прямо в текст: «Land Cruiser 200 дизель 2.6».
- Ценовые рамки передавай отдельно: `--min-price` / `--max-price` (рубли), не в тексте.

## Шаг 3. Поиск

`"args": ["search","--query","<запрос>","--limit","5"]` (плюс `--min-price` /
`--max-price` / `--city` при необходимости). Разбери JSON, покажи топ-5: номер,
название, цену, ключевые факты, ссылку. Добавь короткий вывод по цене: диапазон и
ориентир («примерно X–Y ₽, обычно около Z»). Запомни массив `results` для шага 4.

## Шаг 4. Детали объявления

Если пользователь спрашивает про конкретную карточку («первое», «тот за 4 млн») —
сначала отвечай из уже полученного `description`. Если нужны подробности, которых
там нет, вызови `["details","--url","<url из results>"]` и ответь по полю `item`
(в т.ч. `item.params`).

## Статусы ответа

- `need_city` — спроси город. `need_slug` — определи slug сам.
- `blocked` — Avito показал капчу/блокировку. Сообщи, предложи повторить позже.
- `empty` — ничего не найдено. Предложи смягчить фильтры/цену.
- `error` — покажи `message`.

## Заметки

- Парсинг публичных страниц, не официальный API — для личных оценочных запросов в
  разумном объёме. При частых блокировках нужен прокси (сейчас не настроен —
  сервер ходит на Avito напрямую).
- Если forkd вернул `timed_out: true` — поиск не уложился в лимит; повтори или
  сообщи пользователю.
